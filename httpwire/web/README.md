# @cplieger/httpwire

The TypeScript half of [github.com/cplieger/go/httpwire](https://github.com/cplieger/go/tree/main/httpwire). It decodes the wire a Go `httpwire` API answers: the error envelope, list pages and the idempotency key a write sends.

## Install

```sh
npx jsr add @cplieger/httpwire
# or
npm i @cplieger/httpwire
```
