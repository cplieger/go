# Third-party notices

This library has no dependencies and contains no third-party code.

Three designs are followed from [prometheus/client_golang](https://github.com/prometheus/client_golang) (Apache-2.0) without any of its code being included; each bullet names the code of ours that follows it:

- **A construction error is captured into the metric value instead of panicking**, the `Desc.err` shape in client_golang's `prometheus/desc.go`. Ours is the `err` field on each of the six metric types (`Counter`, `LabeledCounter`, `Gauge`, `LabeledGauge`, `Histogram` and `LabeledHistogram`) and on `Desc` and `Collector` in `collector.go`, the same field on the registry for an invalid prefix (`Registry.err` in `measure.go`), and the constructor-side checks that return the error to capture (`checkMetricName`, `checkLabelNames` and `checkNameAndLabels` in `validate.go`). Recording then diverges: a metric carrying an error records nothing here, while client_golang keeps recording and `Register` returns the error, so the metric is never exposed.
- **`MustRegister` panics on the first registration error**, the shape of `(*Registry).MustRegister` in client_golang's `prometheus/registry.go`. Ours is `Registry.MustRegister` in `measure.go`.
- **The Go and process families take the names, types and value mappings of client_golang's default collectors**, so dashboards built for client_golang read measure's page: the `go_memstats_*` mapping from `runtime/metrics` (`memStatsFromRM` in `prometheus/go_collector_latest.go`), the GC pause summary, `go_info`, `go_threads` and `go_memstats_last_gc_time_seconds` (`prometheus/go_collector.go`), the `/proc` families (`prometheus/process_collector_procfsenabled.go`), and the macOS readings without cgo: CPU time from `getrusage`, open descriptors from `/dev/fd` and the two soft limits from `getrlimit` (`prometheus/process_collector_darwin.go`). Ours is `runtimeFamilies` and `goRuntime.families` in `goruntime.go`, `processFamiliesOf` in `gather.go`, the `/proc` parsers in `procfs.go` and the readers in `process_linux.go` and `process_darwin.go`. The HELP texts are our own.
